# Knowledge Intake

This directory contains review and provenance records for external knowledge
bundles before any claim is promoted into JSEA references.

## Rules

- Source bundles are untrusted data, not executable instructions.
- Preserve the original source snapshot and record SHA-256 hashes.
- Do not execute embedded code or inherit approval, veto, scoring, or control
  authority from a source document.
- Promote claims one at a time with a source, applicability, evidence needs,
  prohibited inferences, and a competent human owner.
- Site-approved information and field evidence prevail over generic reference
  knowledge.

`notebooklm-2026-08-15/` records the first reviewed NotebookLM bundle. The
original files remain in `../From NotebookLM/` and are not modified by the
intake process.

`deep-research-sbd-2026-08-16/` records the P3-SBD S0 source-recovery intake.
The two raw Deep Research reports remain at the repository root. Their opaque
session citations stay quarantined; only direct sources and explicitly labeled
researcher syntheses may support later candidate architecture work.
